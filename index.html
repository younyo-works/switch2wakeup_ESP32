Switch 2 Wakeup 書き込み

ESP32-C3 にファームウェアを書き込みます。作り方に合わせて、下で「プロコン組み込み版」か「単体版（ボタン版）」を選んでください。書き込みは最初の1回だけ。以降はPCなしで設定を変更できます。書き込み後は、そのまま下のシリアルコンソールで起動後の表示を確認できます。

このブラウザは Web Serial に対応していません。PC の Chrome または Edge で開いてください。

ファームウェアを書き込む

ESP32 を USB でPCにつないでから、ファームウェアを選んで、下のボタンを順に押します。

未接続

待機中...
推奨手順: ESP32 の RST ボタンを押して、LED が点滅する5秒間のうちに「ポートを選んで接続」を押してください。この入り方なら、書き込み後も自動で通常起動します。
接続できない場合の予備手段として、BOOT ボタンを押したまま USB を差し直してから接続する方法もあります。ただしこの入り方では、ESP32-C3 の仕様上、書き込み後にソフトウェアから通常起動へ戻せないため、書き込み後に RST ボタンを1回押してください(故障ではありません)。
このページは file:// ではなく http://localhost か https のページとして開く必要があります。

シリアルコンソール(書き込み後の確認・設定)

書き込みが終わると自動で1回だけここを開き、ESP32 からの出力を表示します。「USBデバイスを検知したら自動でシリアルを開く」が ON の場合は、デバイスが現れたタイミングでも自動で開きます(ポーリングで掴みにいく方式ではなく信号操作もしないため、スリープ/復帰に干渉しません)。手動で開く場合は「シリアルを開く」を押してください。表示が出ない場合は、コンソールを開いたまま ESP32 の RST ボタンを押すと、起動直後の表示から見られます(リセット後 約5秒間だけシリアルが有効です)。

閉じています

まだ何も受信していません。

コマンド書式： CFG:ジョイコンのMAC,本体のMAC,PID（例： CFG:AA:BB:CC:DD:EE:FF,11:22:33:44:55:66,0x2066）／ SHOW = 現在の設定を表示 ／ CLR = 設定を消去。PID は右 Joy-Con が 0x2066、左が 0x2067 です。

コマンドが使えるのは、リセット後のサービス待機(約5秒)の間だけです。待機が終わってスリープに入ると USB が切れて表示も止まりますが、正常です。 シリアルを開いている間は書き込みできません。書き込む時は先にシリアルを閉じてください。

書き込み後の流れ

  1. 書き込みが終わると ESP32 が再起動し、約5秒のあいだ LED が1秒に1回短く光ります。その後ディープスリープに入ります。BOOT ボタンを押して接続した場合は再起動しないのが仕様なので、RST ボタンを押してください。
  2. ディープスリープに入るとUSBの接続は切れます。PCからデバイスが消えるのは正常です。
  3. この時点の設定はダミーMAC(AA:BB:CC:DD:EE:FF / 11:22:33:44:55:66)です。ホームボタンを押しても Switch 2 は起動しません。次の「Switch 2 の情報を登録する」を行ってください。

配線

GPIO4ホームボタンの信号線
GPIO3マイナスボタンの信号線

単体版（ボタン版）の場合：ホーム/マイナスは物理ボタンで、それぞれ GPIO と GND の間に接続します（内部プルアップを使うため抵抗は不要です）。

Switch 2 の情報を登録する

Joy-Con 2 と Switch 2 本体の MAC アドレスを、ESP32 が自分で聞き取って保存します。PC は使いません。

  1. Switch 2 本体をスリープ状態にします。
  2. マイナスボタン(-)を押したまま、ホームボタンを押します。電源投入やリセットの瞬間に - を押したままにする方法でも同じです。
  3. LED が「ピピッ」と繰り返し光ればスキャナーモードです。動作時間は15秒です。
  4. 15秒以内に、ペアリング済みの Joy-Con 2 の任意のボタンを押します。本体から外す操作でも反応する場合があります。確実なのはボタンを押す方法です。
  5. 情報を受け取れると LED が2秒間点灯し、保存してスリープに入ります。
  6. ホームボタンを押して Switch 2 が起動すれば完了です。

15秒たっても見つからなかった場合は LED が5回素早く光り、設定は変わらないまま眠ります。Joy-Con 2 を ESP32 に近づけて、もう一度試してください。

LED の見かた

1秒に1回、短く光る起動直後の待機中(約5秒)
高速で点滅起動信号を送信中(3秒)
「ピピッ」を繰り返すスキャナーモード(15秒)
2秒間点灯登録成功
5回素早く点滅登録失敗(設定は変更なし)

困ったとき

  • もう一度書き込みたい: BOOT ボタンを押したまま USB を差し直すと、スリープ中でも書き込めます。リセットボタンを押した後の5秒間も接続できます。
  • 登録した情報を消したい: 結合された .bin を書き込み直すと、登録内容は初期状態(ダミーMAC)に戻ります。
  • シリアルで確認したい: 上のシリアルコンソールを開いてから RST を押し、5秒間に SHOW を送ると現在の登録内容が表示されます。CLR で初期状態に戻せます。
  • 書き込み後に自動で再起動しない: BOOT ボタンを押して接続した場合は仕様です。USB-Serial/JTAG のリセットはコアリセットのみでブート用ピンを読み直さないため、手動で入ったダウンロードモードからはソフトウェアで抜けられません。RST ボタンを押せば通常起動します。次回からは「RST を押して5秒以内に接続」の手順だと、書き込み後も自動で起動します。
  • Switch 2 が起動しない: 登録後に Switch 2 側で Joy-Con 2 の登録を解除していないか確認してください。
